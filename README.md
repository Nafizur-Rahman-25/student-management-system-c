# Student Management System in C
 
A console-based Student Management System built using the C programming language.
 
## Features
 
- Add Student
- View All Students
- Search Student by ID
- Update Student Information
- Delete Student
- Save Students to File
- Load Students from File
- Duplicate ID Validation
- Full Name Support
 
## Concepts Used
 
- Structures
- Arrays
- Functions
- Loops
- String Handling
- File Handling
- Data Persistence
 
## Project Files
 
```text
student-management-system/
├── main.c
├── students.txt
└── README.md
```
 
## How to Compile and Run
 
### Linux / macOS
 
```bash
gcc main.c -o app
./app
```
 
### Windows
 
```bash
gcc main.c -o app.exe
app.exe
```
 
## Sample Features
 
- Store student information
- Search students instantly by ID
- Update existing student records
- Persist data using file handling
- Automatically load saved records at startup
